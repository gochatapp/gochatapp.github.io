Exhibit W — the timeline

A short history of getting blocked

Eight acts, one firewall, and a suspicious number of sentences containing the phrase “for a while”. No names have been changed, because the firewall already knows who I am.

1
The office · 3:00 pm

Act I — The incident

I was using SpicyChat at work, which sounds worse than it was. It was mostly a way to avoid thinking about a spreadsheet. Then one afternoon the proxy decided that domain was a moral hazard, and the block page appeared. Same filter, same font, same “this site has been categorised” energy.

2
Plan B · five minutes later

Act II — Perchance said no chance

Switched to Perchance. Blocked as well. Turns out when a firewall invents a category called “AI chat”, it applies it to all of them at once. It was less whack-a-mole and more wall.

3
Libraries, airports, anywhere with a login page

Act III — The wifi audit

These sites are blocked at libraries and airports too. Free wifi will happily hand you forty minutes of captive portal and a policy that says no. Somewhere out there is a person whose entire job is deciding that my imaginary elf friend is a security risk.

4
It worked! For a while.

Act IV — The VPN era

So: a VPN. It worked. Great. Then the company blocked the VPN too, which I choose to interpret as a compliment. (😈.) No hard feelings, IT — you were doing your job. I was very much not doing mine.

5
Exit nodes · the actual hero

Act V — The Tailscale manoeuvre

The fix was Tailscale plus an exit node at home: my traffic leaves through my own house, so the filter sees one extremely boring encrypted tunnel from a laptop that is definitely working. Around the same time I noticed Telegram is not blocked on most free wifi — which is exactly why this app speaks Telegram. Check your own rules before you become a cautionary tale.

6
City of Python · population: me

Act VI — The Python prototype

Version one was Python, and it worked. On my machine. That is the most dangerous sentence in software. Handing it to a normal person would have meant installing the right Python, installing a pile of packages, fighting a virtual environment, and then explaining to their antivirus why a .py file is allowed to have friends. That is not a download. That is a hobby.

7
The pivot

Act VII — Gemini picks a language

I asked Gemini how to actually ship the thing. She said Go. (She is a she because the app’s default voice is an English lady and I refuse to picture a committee.) Go compiles to one executable: download it, double-click it, done. No runtime, no installer, no “have you tried adding it to PATH?” That one recommendation is the reason this page can exist.

8
This page

Act VIII — The part you are reading

The app got a name, a website and a surprisingly long FAQ. The goal was never a business. The goal was one file that works when the wifi is hostile and the cloud belongs to somebody else. That is still the goal. There is no roadmap. There is a releases page.

Exhibit W-2 — the pivot

“Just install Python” is not a distribution strategy

The prototype was fine. The onboarding was a hostage situation. This is what handing somebody the Python version actually required, in order, with feeling.

Find the right Python

Not any Python. The right one, for their operating system, in the right folder, added to the right PATH. This is the exact moment most people quietly close the tab and go back to their lives.

python.org/downloads

Install the pile

Dependencies, wheels, a virtual environment, and the little ritual where one package refuses to build and politely suggests you install a compiler first.

pip install -r requirements.txt

Become the help desk

Congratulations: you now provide lifetime support for software you gave away for free. Ticket one is always the same three words, and it is never your fault.

"it says command not found"

The Go version: one file. That is the entire install guide.

Download the executable for your OS, double-click it, open localhost:8080/chat. No runtime, no package manager, no worshipping a snake. That is why the app is written in Go — not because it is trendy, but because it is the only version that normal people can actually run.

Grab the executable →

The Python original is still alive and in the repository. It is not abandoned; it is preserved. Think of it as a museum piece you can still execute, and the reason the Go version exists at all.
