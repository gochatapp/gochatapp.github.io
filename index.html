Overview

Designed for personal control

Character XI runs as a self-hosted application. You operate the server, configure the AI connection, and decide how you access your conversations.

Local operation

Your files stay with you

Conversation files are stored on the computer running Character XI. You can manage, back up, or remove those files yourself.

Telegram access

Connect via Telegram

Launch Telegram on the web (web.telegram.org), Telegram Desktop App, or the Telegram mobile app to start interacting.

Model choice

Connect through OpenRouter

Use an OpenRouter API key to connect Character XI to supported AI models. Model availability and usage costs are determined by the provider. Don't worry there is some free models.

Privacy clarification: Character XI stores its conversation files locally, but prompts are sent to the AI provider you configure for processing. If you use Telegram, messages also pass through Telegram's service. Review the relevant provider policies before sending sensitive information.

Also considered

Character XI vs. SillyTavern

SillyTavern is a genuinely full-featured, open-source chat frontend with a large extension ecosystem — but it is difficult to set up. Getting it running means installing Node.js, cloning a Git repository, and running commands in a terminal before you ever send a message. Character XI gives up some of that plugin depth in exchange for a setup almost anyone can finish: download a single file and run it.

Feature Character XI SillyTavern
Installation ✓ Single file download ✕ Clone repo + dependencies
Node.js Required ✓ None ✕ Node.js required
Setup Difficulty ✓ Download and run ✕ Terminal commands to install
Updates ✓ Download the new release ✕ Pull changes & reinstall
Telegram Access ✓ Built-in ✕ Not built-in
Feature Depth ✓ Focused, works out of the box ✓ Very full-featured with plugins
Cost ✓ Free software ✓ Free and open source
The trade-off: If you want maximum features and are comfortable with Node.js, Git, and the command line, SillyTavern is a powerful, full-featured option. Character XI is for people who want a capable chat app that simply works after a single download — no Node.js, no terminal, no dependency wrangling.

Questions

Frequently asked questions

Is Character XI free?

Yes. Character XI is free software. You may still incur charges from the AI model provider if you select a paid model or use a paid service.

Where are my conversations stored?

Character XI stores its conversation files on the computer where the application is running. Back up the relevant files if you want to preserve your conversations.

Does my data ever leave my computer?

Your local chat files remain on your computer, but prompts must be sent to the configured AI provider to generate replies. Telegram messages are also handled by Telegram when you use the bot.

Do I need Telegram?

Telegram is required for the Telegram interface. Use the browser interface for browser-based access. This release's setup also requires an OpenRouter API key for AI model access.

Does OpenRouter cost money?

OpenRouter has free and paid model options. Free models may have usage limits or availability restrictions. Check the current model pricing and terms before use.

Can I run Character XI on a Raspberry Pi?

Use the Raspberry Pi quickstart to check supported hardware, operating system requirements, and installation instructions for your device.
