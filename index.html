Exhibit B — the shopping list

The $0 plan still has a shopping list

Three things stand between you and a first reply: a computer, an Ollama API key, and — if you want it in your pocket — a Telegram user id plus bot token. All free, pasted once, and none of them renews.

A computer

Windows, macOS, Linux, Raspberry Pi or FreeBSD. One executable, no runtime, no installer. If it can open a browser, it can host this.

chat-windows-x64.exe

An Ollama API key

Free from ollama.com/settings/keys. Paste it once in the setup page and pick Gemma 4 31B — the model this app already defaults to — so your first reply lands in seconds instead of after a multi-gigabyte download. Running Ollama locally instead? That route needs no key.

OLLAMA_API_KEY

Telegram: user id + bot token

Two values, pasted once: @BotFather makes the token, @userinfobot tells you your id. The app wants both or neither. Add them and the same conversation mirrors to your phone; skip them and the browser chat still works.

TELEGRAM_USER_ID · TELEGRAM_BOT_TOKEN

Fastest route to a first message: download → paste the Ollama key → pick Gemma 4 31B → open localhost:8080/chat. Telegram can wait; adding it later does not move your chats.

Why it's free

Because your computer is the server

Character XI has no data center to rent, no content moderators to pay, and no investors to impress. The expensive part — the machine — is already on your desk.

Your chats sleep on your disk

Every conversation is written to a local .txt file in the chats folder. Delete the folder and it is gone forever — no account to close, no export request, no “download your data” ZIP that arrives in 45 days.

$0.00 is the whole price

Not $0 for the first month. Not $0 with a card on file. There is no billing system in the codebase because there is nothing to bill. The invoice is a joke and the price is not.

Free models, no meter

Plug in Gemma 4 31B through a free tier, run something smaller locally with Ollama, or point it at any OpenAI-compatible endpoint. You pick the brain, and you can swap it whenever a better one ships.

Browser or Telegram, your call

The app serves its own chat UI at localhost:8080/chat. Add a Telegram user id and a bot token, and the same conversation mirrors to your phone — same state, same history, still your machine.

You write the rules

No “your character suddenly got shy and changed the subject”. You own the role description, the role library and the temperature. Whatever tone you set is the tone you get.

Nothing to shut down

If this project vanished tomorrow, your copy keeps working. That is what software as a file looks like — no uptime status page, no acquisition announcement, no Chapter 11.

Download the binary for your machine

Windows, Linux, macOS, Raspberry Pi and FreeBSD builds all live on the releases page. There is no installer, because there is nothing to install.

chat-windows-x64.exe

Double-click it

macOS and Linux get one extra line so the file knows it is allowed to exist. Then the app starts its own local server.
